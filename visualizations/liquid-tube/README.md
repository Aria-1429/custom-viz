# Custom Viz Liquid Tube

Splunk Dashboard Studio 向けのカスタムビジュアライゼーション（試験管型の液体ゲージ）。

**1 viz = 試験管1本**で、単一の値を液面の高さで表す。ガラス・液体・気泡は
すべて **WebGL のフラグメントシェーダ**で描いており、屈折・透過・フレネル反射を伴う立体的な
見た目になる（SVG や CSS では表現できない質感）。

**背景を透過できる**ため、ダッシュボードの背景やパネルの上にそのまま重ねられる。

## 特徴

- データドリブン描画（値に応じて液面が変わる。複数行は集計して1値に畳む）
- **試験管の外側のグローを消せる**（`0` で完全に消える）
- **背景の透過**（既定 ON）。透過を切って任意の背景色を敷くことも可能
- **液体の透過**（Beer-Lambert の吸収則。「液体の濃さ」で調整）
- **値のしきい値で色分け**（`editor.threshold` で範囲を動的に追加）または**試験管ごとに色を割り当て**
- **気泡**：個体差（大きさ・傾き・速度）＋時間による形の揺らぎ。真円にならない
- ガラスの質感：屈折・フレネル反射・肉厚による減衰・口のふち（リム）
- 液面の波・メニスカス（表面張力の盛り上がり）
- ラベル／値の表示切替、単位・小数桁数の指定
- ドリルダウン対応（試験管のクリックでトークンを設定）
- ライト / ダークテーマ対応、パネルサイズへの自動フィット
- 空データ・数値列なし・型不一致に対するガード処理

## 動作要件

**WebGL2 が必要**です。Splunk のカスタム viz iframe 内で webgl2 が使えることは
実機で確認済み（2026-08-02 / Splunk 10.4.1・Chrome・ANGLE D3D11 経由）。
WebGL2 を取得できない環境では、その旨のメッセージを表示して描画を諦めます。

## データ仕様

| 種別 | 説明 |
| --- | --- |
| 必須 | **数値の列**（液面の高さになる） |
| 任意 | **ラベルの列**（試験管の名前） |

**1 viz = 1 本**なので、複数行が来たときは「集計」オプション（既定は最終行）で1つの値に畳む。
試験管を並べたい場合は**パネルを複数配置する**（1 viz に詰め込むと管が細くなり、
屈折や肉厚といった質感が潰れるため）。

列の決め方（優先順）:

1. 編集画面「データフィールド」での指定
2. 未指定なら自動判定（**最初の数値列＝値 / 最初の非数値列＝ラベル**）

```spl
| makeresults count=1
| eval name="CPU", value=78
| table name value
```

## オプション（ダッシュボード編集画面）

| セクション | オプション | 説明 |
| --- | --- | --- |
| データフィールド | ラベル / 値 | 使用する列の明示指定（未設定は自動判定） |
| データフィールド | 複数行のときの集計 | `最終行`（既定）/ `先頭行` / `合計` / `平均` / `最大` / `最小` / `件数` |
| 値の範囲 | 最小値 / 最大値 | 液面が空・満杯になる値（既定 `0` / `100`） |
| 色分け | 色の決め方（`colorMode`） | `値のしきい値で色分け`（既定）/ `固定色を使う` |
| 色分け | しきい値と色（`colorBands`） | 「＋」で範囲を動的に追加。各範囲は**下限以上・上限未満** |
| 色分け | 液体の色（`seriesColors`） | 「固定色」選択時に先頭の色を使う |
| 背景 | **背景を透過する**（`transparentBg`） | 既定 **ON**。ダッシュボードの背景を透かす（→ [背景の透過](#背景の透過)） |
| 背景 | 背景色（`bgColor`） | 透過しない場合に使う色。**未設定ならテーマに合わせる**（ライトテーマで黒くならない） |
| 液体の見た目 | 液体の濃さ（`liquidOpacity`） | `0` で透明・背景が透ける / `1` で不透明（既定 `0.45`） |
| 液体の見た目 | 気泡の数（`bubbleCount`） | `0`〜`40`（既定 `18`）。`0` で気泡なし |
| 液体の見た目 | アニメーション速度（`animSpeed`） | `0` で完全停止（静的表示・GPU 負荷ほぼゼロ） |
| 液体の見た目 | 試験管の太さ（`tubeWidth`） | 画面高さに対する比（`0.05`〜`0.35`） |
| 液体の見た目 | 試験管の外側のグロー（`glow`） | `0` で**完全に消える**（既定 `1`） |
| ラベルと値 | ラベル / 値を表示、単位、小数桁数、文字サイズ | 表示の調整 |

### 背景の透過

「背景」→**「背景を透過する」**（既定 ON）で、試験管の周囲が透明になり
**ダッシュボードの背景がそのまま透けます**。実装は以下の3点が揃って成立しています:

- WebGL コンテキストを `alpha: true` / `premultipliedAlpha: true` で取得
- シェーダが **premultiplied alpha**（`vec4(col * alpha, alpha)`）で出力
- viz コンテナの CSS 背景も `transparent`（ここを塗ると canvas の透過が無効になる）

**液体やガラス越しにもダッシュボードの背景が透けます**（v1.2.0 以降）。
シェーダから背景を読むのではなく、**部位ごとに alpha を出力してブラウザに合成させる**
方式のため、iframe の外にある背景でも問題なく透けます。

| 部位 | 透け方 |
| --- | --- |
| 管の外側 | 完全に透過 |
| 液面より上の空洞 | ほぼ素通し（ガラスの曇りぶんだけ） |
| 液体 | 「液体の濃さ」に応じて透ける |
| ガラス（側壁・ふち） | 肉厚と角度に応じて half-transparent |
| 反射・ハイライト | 光っている分は不透明（消えない） |

### 色分け

**しきい値**（既定）は `editor.threshold` で範囲を動的に増減できます。各範囲は
**下限以上・上限未満**で、上限を空にすると「以上」の開いた範囲になります。
どの範囲にも入らない値は既定色になります。

**固定色を使う**を選ぶと、`editor.seriesColors` の**先頭の色**が常に使われます（値によらず一定）。

## 開発

```bash
yarn install
yarn build          # 開発ビルド
yarn build:prod     # 本番ビルド（.spl を作る前は必ずこちら）
yarn verify         # happy-dom によるローカル検証（WebGL はスタブ化）
yarn package        # dist/*.spl を生成
```

`yarn verify` は WebGL を実行できないため、**getContext をスタブ化して uniform に渡る値**
（液面の高さ・色・透過フラグ等）を検証しています。描画そのものの確認は実機で行います。
