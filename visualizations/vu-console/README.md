# VU Console

複数のメトリクスを、レコーディングスタジオの VU メーター（アナログ針の計器）を並べた
「調整卓」として表示する Splunk Dashboard Studio 向けカスタムビジュアライゼーション。

![example](examples/example.png)

## 特徴

- **1メトリクス = 1メーター**。データの列数（または行数）に応じてメーターが増減し、
  コンテナ実寸から列数を自動決定してグリッドに敷き詰める
- **針はバネ物理**（減衰2次系）で振れる。値の急変時に少しオーバーシュートして戻る
  「アナログらしさ」を再現。描画は rAF ループが SVG の transform を直接更新する
  ハイブリッド方式で、React の再レンダリングを介さない。**全メーターが静止したら
  ループを自動停止**するため、複数枚並べても CPU を食い続けない
- **ピークホールド針**（赤の細針）が最大振れ位置に残り、保持時間（既定 2.5 秒）を
  過ぎるとゆっくり現在値へ降りる
- **しきい値の色帯**（`editor.threshold`）を目盛りの外周に弧として描画。
  帯は編集画面で何段でも追加でき、**最上位の帯に入るとピークランプが点灯**する
- **文字盤の質感を選べる**：ビンテージ（クリーム地・黒針）／ダーク（黒文字盤・白針）／
  テーマ連動（ライト=ビンテージ、ダーク=ダーク）
- **針の振れ幅**は VU 標準の 90° のほか 120°／150°（スピードメーター風）を選択可能。
  開き角に応じて針軸の位置と半径を自動調整し、端の目盛り数値が見切れない
- **メーターのクリックでインタラクション発火**（`value.click`）。トークン設定・
  リンク遷移をダッシュボード編集画面の「インタラクション」から設定できる
- OS の「視差効果を減らす」設定（prefers-reduced-motion）では針を即時反映にする

## データ仕様（2形態を自動判定）

### 横持ち（1列 = 1メーター）

数値の列がそれぞれメーターになる。ラベルは列名。
複数行あるときは「値の決め方」（最終行／先頭行／平均／最大／最小／合計）で1値に畳む。

```spl
| makeresults count=5 | streamstats count as n
| eval cpu=40+n*10, mem=30+n*6, disk=10+n*3
| table _time cpu mem disk
```

### 縦持ち（1行 = 1メーター）

「文字列列 × 数値列」の形。文字列列がラベル、数値列が値になる。

```spl
| makeresults format=csv data="host,load
web01,42
web02,71
web03,93
db01,12"
```

自動判定は「数値列が1つ・文字列列あり・複数行」なら縦持ち。
判定を固定したいときは「データの形」オプションで横持ち／縦持ちを明示する。

## 主なオプション

| セクション | オプション | 内容 |
|---|---|---|
| データ | 対象フィールド | メーターにする数値列を選択（空欄で数値列すべて） |
| データ | データの形 | 自動判定／横持ち／縦持ち |
| データ | 値の決め方 | 横持ちで複数行のときの畳み方（最終行／平均／最大…） |
| 目盛りの範囲 | 最小値・最大値 | 目盛りのレンジ（既定 0〜100） |
| 目盛りの範囲 | 範囲を自動決定 | データの最大値から上限を 1/2/5×10^k へ切り上げ |
| 色と質感 | 値の範囲と色 | しきい値の色帯（＋で段を追加）。最上位の帯でランプ点灯 |
| 色と質感 | 文字盤の質感 | テーマ連動／ビンテージ／ダーク |
| 計器の表示 | 針の振れ幅 | 90°（VU 標準）／120°／150° |
| 計器の表示 | 単位ラベル | 文字盤中央の表記（例: %, ms, VU） |
| 針の動き | ピーク針・ピーク保持（秒） | ピークホールド針の表示と保持時間 |
| 針の動き | 針を物理で振る | OFF で即時反映（アニメーションなし） |
| レイアウト | 列数の上限・メーター数の上限 | 0=自動／既定 12（最大 24） |

## インタラクション（ドリルダウン）

編集画面の「インタラクション」で「トークンを設定」を追加すると、メーターのクリックで
トークンが入る。`key` に指定できる値:

- `name` … クリックしたメーターのラベル（列名またはラベル列の値）
- `value` … そのメーターの現在値
- `row.<フィールド名>.value` … 元になった行の各フィールド
  （縦持ち=その行、横持ち=最終行）

## 開発コマンド

```bash
yarn install
yarn build:prod   # 本番ビルド（.spl を作る前は必ずこちら）
yarn package      # dist/<app>-<ver>-<hash>.spl を生成
yarn verify       # happy-dom によるローカル検証（38 チェック）
```

## 制限・既知の注意

- 針のアニメーションは各メーター独立のバネ演算だが、**静止後は rAF を止める**ため
  常時アニメーションではない（撮影・PNG 書き出しでも針は最終角で写る）
- 「範囲を自動決定」を使うと目盛りが 0〜1K などへ広がるが、**色帯はそのまま**なので
  既定の帯（70/85）だと大半が最上位帯の色になる。範囲を変えたら「値の範囲と色」も
  合わせて調整すること
- ライトテーマでの描画はローカル検証（テーマ切替でビンテージ文字盤になること）まで
  確認済み。実機のライトテーマでのスクリーンショットは未取得
