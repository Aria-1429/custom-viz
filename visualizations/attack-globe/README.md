# Attack Globe
![表示例](examples/example.png)

Splunk Dashboard Studio 向けのカスタムビジュアライゼーション（回転する3D地球儀のアタックマップ）。

**WebGL フラグメントシェーダでレイトレースした球体の地球**の上に、「起点（src）→ 終点（dst）」の
大円アークを描き、光の筋が流れるアニメーションで攻撃・通信の流れを可視化する。
平面地図の [World Map](../world-map/) に対して、こちらは「回る地球儀」。SOC のモニタ壁で
足を止めさせる展示用途を主眼にしている。

地図データ（`world-atlas`＝Natural Earth）はビルド時にバンドルされ、陸地テクスチャは
**初期化時にポリゴンからラスタライズ**して生成する。**実行時のインターネット通信は不要**
（本番 Splunk 環境の制約に準拠）。**WebGL2 が必要**（利用できない環境ではメッセージを表示）。

## 特徴

- **本物の球体**：レイ・球交差の解析解によるレイトレース。正射影で歪みなく描画
- **大気の縁光**：フレネル項による青い縁光＋球外のハロー（強さ調整可・0で消える）
- **陰影3モード**：柔らかい陰影（既定）／フラット／**昼夜**（太陽が約2分で地球を一周し、
  夜側が暗くなるターミネーター表現）
- **経緯線グリッド**（15度間隔）と**2階調の国境線**（表示切替可）
- **大円アーク**：起点→終点を球面に沿う弧で結び、**球の裏側に回った区間は自動的に隠れる**。
  ベース軌道は **ぼかしフィルタ付きの発光ハロー＋細い芯線** の2本構え（World Map と同じ質感）
- **流れる彗星**：弧に沿ってテーパー形状の光の帯が流れ、**終点到達時にリップル**が広がる
  （canvas 2D によるポリゴン1回塗り。アルファが累積しないので白飛びしない。周期変更・停止可）
- **着弾点のホットスポット**：放射グラデーションのグロー＋白寄りのコアドット
- **地球儀の操作**：ドラッグで回転（慣性付き）、ホイールでズーム、ダブルクリックで初期表示に復帰
- **自転**：放置すると自動でゆっくり回る（周期指定・0で停止。操作すると一時停止し、
  2.5秒後に再開）
- **色分けの基準は任意の列**（ログ種別 / ステータス / 深刻度 …）。色は「カテゴリ名|色」で
  ユーザーが明示指定する。**件数（count）のしきい値**での色分けも可能（`editor.threshold`）
- **凡例**にカテゴリ別件数と「表示◯◯／全◯◯件」を表示
- **ドリルダウン対応**（弧・着弾点のクリックでトークンを設定し、他パネルと連動）
- カスタムツールチップ（起点→終点・カテゴリ・件数）
- **背景透過**に対応（ダッシュボードの背景に地球が浮かぶ）
- ライト / ダークテーマ対応、パネルサイズに自動フィット、空データ・型不一致へのガード処理

## データ仕様（フィールド）

[World Map](../world-map/) と同じ仕様。同じ SPL がそのまま使える。

| 種別 | フィールド名（候補） | 説明 |
| --- | --- | --- |
| 必須 | `src_lat` / `src_lon` | 起点の緯度・経度 |
| 必須 | `dst_lat` / `dst_lon` | 終点の緯度・経度 |
| 任意 | 色分けカテゴリ（`category` / `type` / `log_type` / `event_type` / `status` / `protocol` / `severity` / `threat_level` / `level`） | 任意の文字列。色は編集画面の「色分け」で明示指定する |
| 任意 | `count`（`events` / `total`） | イベント数（線の太さ・凡例の件数に使用） |
| 任意 | `src_name` / `dst_name` | 起点・終点の表示名（ツールチップ＋地球上のラベル） |

フィールドの決め方（優先順）:

1. 編集画面「データフィールド」セクションのフィールド選択（任意の列名を割り当て可能）
2. 未選択の場合は上表の候補名で自動判定（大文字小文字を問わない）

## オプション（ダッシュボード編集画面）

| セクション | オプション | 説明 |
| --- | --- | --- |
| データフィールド | 送信元/宛先の緯度・経度 ほか | 使用する列の明示指定（未設定は自動判定） |
| 表示 | タイトルの文字列（`titleText`） | 既定 `GLOBAL ATTACK GLOBE`。空欄で非表示 |
| 表示 | 凡例を表示（`showLegend`） | カテゴリ別件数と総件数を表示 |
| 表示 | 地点の表示名を地球上に表示（`showPointNames`） | `src_name` / `dst_name` を点の脇に表示 |
| 表示 | 光の筋の周期（`flowPeriod`） | 秒。`0` で停止 |
| 表示 | 件数による線の太さの強調度（`widthScale`） | `0` で一律の細線 |
| 表示 | 描画する矢印の上限（`maxArcs`） | count の多い順に N 本。`0` で無制限 |
| 地球の見た目 | 陰影（`shadeMode`） | 柔らかい陰影 / フラット / 昼夜 |
| 地球の見た目 | 経緯線グリッド / 国境線 | 表示切替 |
| 地球の見た目 | 大気の光（`atmosphere`） | `0`〜`2`。`0` で消える |
| 地球の見た目 | 地図テクスチャの解像度（`textureSize`） | 低 1024 / 中 2048（既定）/ 高 4096 |
| 地球の見た目 | 陸地の色 / 海の色 | 未設定ならテーマに合わせる |
| 視点 | 初期表示の中心の経度・緯度 | 例: 経度 `135`・緯度 `35` で日本正面 |
| 視点 | 初期ズーム倍率（`initialZoom`） | `1`〜`12` |
| 視点 | 自転の周期（`rotatePeriod`） | 秒/周。`0` で停止（既定 `60`） |
| 視点 | ドラッグ回転・ホイールズームを有効にする（`interactive`） | OFF で固定表示 |
| 色分け | 色分けモード（`colorMode`） | `カテゴリ列の値`（既定）/ `件数（count）のしきい値` |
| 色分け | 件数のしきい値と色（`countThresholds`） | 「＋」で範囲を追加。各範囲は**下限以上・上限未満** |
| 色分け | カテゴリごとの色（`categoryColors`） | 1行に1つ「カテゴリ名\|色」（例: `attack\|#ff5a2e`） |
| 色分け | 上記に無いカテゴリの色（`fallbackColor`） | 未マッピングのカテゴリに使う色 |
| 背景 | 背景を透過する / 背景色 | 透過 ON でダッシュボードの背景に地球が浮かぶ |

### ドリルダウン（トークン設定）

`config.json` は `link.click`（弧）と `point.click`（着弾点）を宣言済み。
編集画面の「インタラクション」で「トークンを設定」を追加すると、クリックした行の
`row.src_lat.value` / `row.dst_name.value` / `row.category.value` などをトークンに入れられる。
※ 編集モード中は viz 内のマウス操作がホストに遮断されるため、クリックの動作確認は表示モードで行う。

## World Map との棲み分け

| | World Map（平面） | Attack Globe（球） |
| --- | --- | --- |
| 全地点の一覧性 | ◎ 常に全世界が見える | △ 裏側は見えない（回して見る） |
| 展示インパクト | ○ | ◎ 回る・光る・浮かぶ |
| 地名ラベル・クラスタリング | ◎ あり | 表示名のみ（クラスタリングなし） |
| 拡大時の詳細国境（50m） | ◎ あり | なし（テクスチャ解像度で調整） |

運用ダッシュボードの分析には World Map、ロビーや SOC の壁掛けには Attack Globe が向く。

## 開発

```bash
yarn install
yarn build        # 開発ビルド
yarn verify       # happy-dom によるローカル検証（WebGL/2D canvas はスタブ）
yarn build:prod   # 本番ビルド（.spl を作る前に必須）
yarn notices      # THIRD_PARTY_NOTICES.txt を生成
yarn package      # dist/*.spl を生成
```

## デプロイ（再インストール・再起動なし）

1. `npm version <patch|minor> --no-git-tag-version` でバージョンを上げ、`package/app/app.conf` の version も同期。
2. `yarn build:prod && yarn package` で新しい `.spl` を生成。
3. Splunk Web「Install app from file」で **"Upgrade app"（上書き）にチェック**してアップロード。
4. `https://<host>:8000/en-US/_bump` で **Bump version** → ブラウザをハードリロード（Ctrl+Shift+R）。

## 地図データの出典・ライセンス

- 国境ポリゴン: **Natural Earth**（`world-atlas` パッケージ経由の 110m 解像度）。
  Natural Earth は**パブリックドメイン**（クレジット表記不要・商用可・改変可・再配布可）。
  <https://www.naturalearthdata.com/about/terms-of-use/>
- バンドルされる OSS のライセンス条文は `THIRD_PARTY_NOTICES.txt`（`.spl` にも同梱）を参照。

### [1.1.1] - 2026-08-09

#### 修正

- **スピナーが永遠に回り続けることがある問題への対策**（全 viz 共通の横展開）。
  公式 `useDataSources` は「render 時に現在値でシード → `useEffect` で購読」の構造で、
  その間に届いた更新を取り逃す（ホストは購読登録時に現在値を再送しない）。
  サーチ完了の最終通知をこの隙間で落とすと `loading` のまま固まる。対策として、
  loading 中は `getDataSources()` を 500ms 間隔で読み直し、ホスト側が完了済みなら
  その値を採用する（`useDataSourcesWithRescue`）。完了後はポーリングしない。
  不定期・初回表示時に発生しやすく、リロードで直る症状はこれが原因とみられる。
  描画・オプションの挙動に変更はない。

`.spl`: `dist/custom_viz_attack_globe-1.1.1-2bb5ec3.spl`

### [1.1.0] - 2026-08-06

#### 変更

- **弧と着弾点の質感を World Map に揃えた**（v1.0.0 の線は単純ストローク＋破線アニメで
  チープだったため、World Map で確立した描画方式を球面へ移植）:
  - ベース軌道を「ぼかしフィルタ付きの太い発光ハロー＋細い芯線」の2本構えに変更。
    アニメ中は軌道を控えめにして彗星を主役に、静止時は芯線を濃くする
  - 光の筋を SVG の破線アニメから **canvas 2D のテーパーポリゴン彗星**に変更
    （sin エンベロープで両端が窄まる帯。グロー2.4倍＋芯の2回塗りで、重ね塗りによる
    アルファ累積＝白飛びが起きない）。**終点到達時のリップル**も追加
  - 着弾点を「単色ドット＋常時パルスリング」から
    **放射グラデーションのグロー＋白寄りコアドット**（線の色から派生色を導出）に変更
  - 線幅の算出を World Map と同式に統一（sqrt 圧縮の正規化。外れ値に引っ張られにくい）
- ローカル検証を新しい描画構造に追随（85件。彗星の停止・ハローのフィルタ適用・
  色ごとのグラデーション生成を含む）
