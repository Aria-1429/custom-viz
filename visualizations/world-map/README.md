# Custom Viz World Map
![表示例](examples/example.png)

https://github.com/user-attachments/assets/49882133-1079-4b8b-86a9-5a6bdacba007

Splunk Dashboard Studio 向けのカスタムビジュアライゼーション（世界地図＋アタックマップ）。

世界地図上に「起点（src）→ 終点（dst）」を弧で描き、弧に沿って光の筋が流れるアニメーションで
流量・イベントの流れを可視化する。**任意の列（ログ種別・ステータス・深刻度など何でもよい）**で
色分けでき、着弾点をホットスポットとして強調表示する。

世界地図データ（`world-atlas`）はビルド時にバンドルされるため、**実行時のインターネット通信は
不要**（本番 Splunk 環境の制約に準拠）。

## 特徴

- データドリブン描画（SPL の結果から起点・終点の弧を自動生成）
- **色分けの基準は任意の列**（ログ種別 / ステータス / プロトコル / 深刻度 …）。深刻度専用ではない
- **色は「カテゴリ名|色」でユーザーが明示指定**（`editor.arrayOfStrings`）。viz が語彙を推測して勝手に色を割り当てることはしない
- 弧に沿って光の筋が流れるアニメーション（速度変更・停止可）
- **編集画面のフィールド選択**（`editor.columnSelector`）で任意の列を緯度経度・色分けカテゴリ等に割り当て可能
- ホットスポットと弧にツールチップ（地点名・カテゴリ・count）
- **凡例クリックで絞り込み**（もう一度押すと解除）
- **ドリルダウン対応**（弧・地点のクリックでトークンを設定し、他パネルと連動）
- **件数に応じた線の太さ**＋**上位 N 件だけ描画**（件数が多いときの視認性・描画負荷対策）
- **ホバーで関連する矢印だけを強調**（どこから来てどこへ行くかを追える）
- **地図アプリのような操作**：マウスホイールでズーム、ドラッグで移動、ダブルクリックで初期表示に復帰
- **中心の経度・緯度を指定**して任意の地域を中心に表示（例: 経度 135 で日本中心）
- **ズームすると地名が現れる**（低ズーム＝国名のみ → 拡大につれて主要都市 → 地方都市）
- **矢印の始点・終点に地点名を常時表示**（`src_name` / `dst_name`。重なりは自動で間引き）
- タイトル / 凡例 / カテゴリフィルタの表示切替オプション
- ライト / ダークテーマ対応（`useTheme` によるガード付き）
- パネルサイズに自動フィット（コンテナサイズを監視して再描画）
- 空データ・必須フィールド欠損・型不一致に対するガード処理

## データ仕様（フィールド）

| 種別 | フィールド名（候補） | 説明 |
| --- | --- | --- |
| 必須 | `src_lat` / `src_lon` | 起点の緯度・経度 |
| 必須 | `dst_lat` / `dst_lon` | 終点の緯度・経度 |
| 任意 | 色分けカテゴリ（`category` / `type` / `log_type` / `event_type` / `status` / `protocol` / `severity` / `threat_level` / `level`） | **任意の文字列**。深刻度に限らずログ種別・ステータス等でよい。色は編集画面の「色分け」で明示指定する（→ [色分けの設定](#色分けの設定)） |
| 任意 | `count`（`events` / `total`） | イベント数 |
| 任意 | `src_name` / `dst_name` | 起点・終点の表示名（**地図上にラベル表示**＋ツールチップ） |

フィールドの決め方（優先順）:

1. 編集画面「データフィールド」セクションのフィールド選択（任意の列名を割り当て可能）
2. 未選択の場合は上表の候補名で自動判定（大文字小文字を問わない）

## オプション（ダッシュボード編集画面）

| セクション | オプション | 説明 |
| --- | --- | --- |
| データフィールド | 送信元/宛先の緯度・経度 ほか | 使用する列の明示指定（未設定は自動判定） |
| 表示 | タイトルを表示 / 凡例を表示 / カテゴリフィルタを表示 | 各オーバーレイの表示切替 |
| 表示 | タイトルの文字列（`titleText`） | 既定 `GLOBAL THREAT MAP`。**空欄にするとタイトルを出さない** |
| 表示 | アニメーション周期（秒、0で停止） | 光の筋がパスを走り切る秒数。`0` で全アニメーション停止（静的表示） |
| 表示 | 件数による線の太さの強調度（`widthScale`） | `0` で一律の細線。大きいほど count の差が太さに出る（既定 `1`） |
| 表示 | 描画する矢印の上限（`maxArcs`） | count の多い順に N 本だけ描く。`0` で無制限（既定 `0`） |
| 表示 | 地点ホバーで関連する矢印を強調（`highlightOnHover`） | 地点にマウスを乗せると、その地点に繋がる矢印以外を薄くする |
| 地図の表示範囲 | 中心の経度 / 中心の緯度 | 地図の中心にする座標（例: 経度 `135` / 緯度 `35` で日本中心）。既定は `0, 0` |
| 地図の表示範囲 | 初期ズーム倍率 | `1` で世界全体。最大 `40`。表示時のズーム状態 |
| 地図の表示範囲 | ホイールズーム・ドラッグ移動を有効にする | OFF にすると地図を固定（静的パネル向け） |
| 地名ラベル | 地名を表示 | ズームに応じて国名 → 都市名が現れる |
| 地名ラベル | 矢印の始点・終点に地点名を表示 | `src_name` / `dst_name` を地図上に常時表示 |
| 地名ラベル | 地名の文字サイズ（px） | 既定 `11`（6〜24） |
| 地名ラベル | 地名の表示量（`labelDensity`） | `0.2`〜`5`（既定 `1`）。大きいほど多く表示（候補数とラベル間隔の両方が連動） |
| 色分け | カテゴリごとの色（`categoryColors`） | 1行に1つ「カテゴリ名\|色」。**ここに書いた色だけが使われる**（→ [色分けの設定](#色分けの設定)） |
| 色分け | 上記に無いカテゴリの色（`fallbackColor`） | 未マッピングのカテゴリに使う既定色 |
| 色分け | 凡例・フィルタの並び順（`categoryOrder`） | 1行に1カテゴリ名。書かなかったものは検索結果の登場順で後ろに並ぶ |
| 色分け | 色分けの呼び名（`categoryLabel`） | 凡例の見出し・フィルタの「すべての〇〇」に使う。空欄なら非表示 |
| 背景 / 陸地 | 背景色・陸地色 | チェック ON 時のみカスタム色（transparent 指定で非表示） |

タイトル文字列は既定で `GLOBAL THREAT MAP`。編集画面の「表示」→「タイトルの文字列」で変更できる
（空欄にするとタイトルを表示しない）。

### 色分けの設定

**この viz は色を推測しない。** 「カテゴリ名|色」で書いたものだけが色の根拠になる。

色分けの基準は深刻度とは限らない（ログ種別・ステータス・プロトコル・部署など何でもよい）ため、
`critical` が `high` より重い、といった**語彙の意味を viz 側で解釈することは一切しない**。
並び順もユーザー指定（`categoryOrder`）に従い、未指定なら検索結果への登場順になる。

編集画面「色分け」→「カテゴリごとの色」に、1行ずつ次の形式で入力する:

```
high|#ff0000
medium|#e6b93c
low|#38a6ff
```

ログ種別で色分けする場合:

```
auth|#00b0ff
firewall|#ff5a2e
dns|#2dd4bf
```

- 区切りは半角の `|`。前後の空白は無視される
- 大文字小文字は区別しない（`HIGH` と `high` は同じカテゴリ）
- 色は `#RRGGBB` / `#RGB` / `#RRGGBBAA` のほか、`red`・`lime`・`navy` 等の基本的な色名も使える
- **書かなかったカテゴリは「上記に無いカテゴリの色」（既定 `#38a6ff`）**で描かれる。
  凡例ではスウォッチが破線で囲まれ、ホバーすると設定方法が表示される
- 解釈できない行（区切りが無い・色が不正）は**黙って無視**される（描画は壊れない）
- 色分け列の値が空の行は `(未分類)` という独立したカテゴリになる

### 絞り込みとドリルダウン

**凡例クリックで絞り込み**：凡例のカテゴリを押すとその弧だけを表示し、
もう一度押すと解除される（右上のフィルタと連動）。選択中の項目は下線＋太字になる。

**ドリルダウン（インタラクション）**：弧・地点をクリックすると、
ダッシュボードの他パネルへトークンを渡せる。使うには編集画面で設定が要る:

1. パネルを選択 → 右パネルの**「インタラクション」**タブを開く
2. 「トークンを設定」などのアクションを追加する
3. 表示モードで弧または地点をクリックする（**編集モードでは動かない**。下記参照）

viz が渡す値:

| イベント | 発火する要素 | 主な payload |
| --- | --- | --- |
| `link.click` | 矢印（弧） | `row.src_name.value` / `row.dst_name.value` / `row.category.value` / `row.count.value` / 緯度経度4種 |
| `point.click` | 起点・終点の地点 | `row.name.value` / `row.category.value` / `row.count.value` / `row.role.value`（`source` or `target`） |

> **注**: トークンが実際に入るかはダッシュボード側のインタラクション定義に依存する
> （viz は「クリックされた事実」を発火するだけで、何をするかはホストが決める）。
> ローカル検証では「要素ごとに正しい payload が登録されているか」までを確認している。

### 地図の操作方法

| 操作 | 動作 |
| --- | --- |
| マウスホイール | カーソル位置を中心にズーム（`1`〜`40` 倍） |
| ドラッグ | 地図を移動（パン） |
| ダブルクリック | 初期表示（オプションで指定した中心・ズーム）に戻す |
| 右下の `×N ⟲` | 同上（ズーム中のみ表示） |

> **注意**: ダッシュボードの**編集モードでは操作できません**。Splunk が編集中にカスタム viz の
> iframe への入力を遮断する仕様のためで、**表示モードでは正常に動作します**。編集中に見え方を
> 決めたい場合は「中心の経度・緯度」「初期ズーム倍率」を右パネルから設定してください。

## 地図データの出典・ライセンス

同梱データはいずれも**パブリックドメイン**で、クレジット表記は不要です。

| データ | 出典 | ライセンス |
| --- | --- | --- |
| 国境ポリゴン・国名 | [world-atlas](https://github.com/topojson/world-atlas)（Natural Earth 110m の再配布） | パブリックドメイン |
| 都市名（約 7,340 件） | [Natural Earth](https://www.naturalearthdata.com/about/terms-of-use/) `ne_10m_populated_places` | パブリックドメイン |

> Natural Earth 公式の利用条件：*"All versions of Natural Earth raster + vector map data found on
> this website are in the public domain."* / *"No permission is needed to use Natural Earth.
> Crediting the authors is unnecessary."*

なお、リポジトリ同梱の `major_cities.csv`（SimpleMaps 由来）は **Splunk 側の lookup 用**であり、
出典表記が必要なライセンスのため **viz のバンドルには含めていません**。

## 開発

```bash
yarn install
yarn build          # visualizations/*/dist を生成
yarn verify         # happy-dom によるローカル検証（Splunk 実機なしでバンドルを検証）
yarn package        # dist/*.spl（Splunk アプリパッケージ）を生成
```

本番向け（minify・ソースマップ無し）は `yarn build:prod` の後に `yarn package` を実行する。

アプリのメタデータ（version / label / author / description / category）は `package/app/app.conf`
に格納されている。Splunk 上での見え方を変えるときはこのファイルを編集する（`package.json` は
Node/npm 用）。

## デプロイ（再インストール・再起動なし）

1. `npm version patch --no-git-tag-version && yarn build && yarn package` でバージョンを上げて `.spl` を生成
2. Splunk Web「Install app from file」で **"Upgrade app"（上書き）にチェック**して `.spl` をアップロード
3. ブラウザで `https://<host>:8000/en-US/_bump` を開き **Bump version**（Splunk 再起動の代替）
4. ブラウザをハードリロード（Ctrl+Shift+R）

## サンプル SPL

lookup 不要（座標を直接指定。フィールド名は自動判定される）:

```spl
31.23,121.47,35.68,139.69,high,300,Shanghai,Tokyo
55.76,37.62,35.68,139.69,high,50,Moscow,Tokyo
-23.55,-46.63,35.68,139.69,medium,80,Sao Paulo,Tokyo
28.61,77.21,35.68,139.69,medium,60,Delhi,Tokyo
40.71,-74.01,35.68,139.69,low,10,New York,Tokyo
-33.87,151.21,35.68,139.69,scan,40,Sydney,Tokyo"
```

`major_cities` lookup を使う場合:

```spl
| makeresults format=csv data="src_city,dest_city,severity,count
London,Tokyo,low,1000
Shanghai,Tokyo,high,2000
Moscow,Tokyo,high,3000
Sao Paulo,Tokyo,medium,4000
Delhi,Tokyo,medium,5000
New York,Tokyo,low,6000
Los Angeles,Tokyo,low,7000
Dallas,Tokyo,medium,8000
Sydney,Tokyo,low,9000"
| lookup major_cities city as src_city OUTPUT lat as src_lat lon as src_lon
| lookup major_cities city as dest_city OUTPUT lat as dest_lat lon as dest_lon
```

深刻度以外（ログ種別）で色分けする場合。編集画面の「色分け」に
`auth|#00b0ff` / `firewall|#ff5a2e` / `dns|#2dd4bf` を入力し、
「色分けの呼び名」に `ログ種別` と入れると凡例の見出しになる:

### [1.7.0] - 2026-07-28

#### 追加

- **タイトル文字列を編集画面から変更できるようにした**（「表示」→「タイトルの文字列」）。
  従来は `optionsSchema` にキーはあるものの editor 項目が無く、
  ダッシュボード定義のソース編集でしか変更できなかった。
  - **空欄にするとタイトルを表示しない**。空文字を「タイトル無し」の意思表示として
    尊重し、既定値へ戻さない（キー自体が無い＝未設定のときだけ既定値）。

#### 変更

- 編集画面のラベル「深刻度フィルタを表示」を **「カテゴリフィルタを表示」** に修正。
  v1.4.0 で色分けを深刻度専用から任意のカテゴリへ一般化した際の表記漏れ。

#### 見送り（実装したが取り消した）

- 日付変更線（経度180度）をまたぐ矢印を**画面の端で2区間に分割**する変更を一度入れたが、
  **実機で弧が途中で途切れて見えたため取り消した**。
  幾何計算としては最短経路を選べていたものの、
  Natural Earth 図法では東京→ニューヨークのように
  **「地図上では直線で繋がって見える経路」まで分割対象になり**、
  太平洋の真ん中で線が切れて見えてしまう。
  矢印は**始点から終点まで1本の連続した曲線**で描く従来の挙動に戻した。

- `dist/custom_viz_worldmap-1.7.0-ea92401.spl`

### [1.6.0] - 2026-07-28

#### 修正

- **ズームするほど地名が減っていた不具合を修正**（最大の実害）。
  `CITY_LABELS.slice(0, N)` で**先に「世界の重要度上位N件」を取ってから**
  画面内かどうかを判定していたため、拡大すると上位N件がほぼ全て画面外になり、
  結果として表示できる地名がごくわずかになっていた。
  - 実測（修正前・日本中心）: `zoom6=9件` → `zoom16=7件` → `zoom40=3件`
    （`zoom40` は上限600件を許可していたのに実際は3件しか出ていなかった）
  - **先に画面内へ絞り、そのうえで重要度順に採る**方式へ変更。
  - 実測（修正後・同条件）: `zoom6=80件` / `zoom16=53件` / `zoom40=34件`
- **「地名の表示量」を上げても表示数がほとんど変わらなかった点を修正**。
  件数の上限だけ動かしてもラベルの重なり判定が固定のままだったため、
  実際の表示数が頭打ちになっていた。**候補数とラベル間隔の両方**を
  `labelDensity` に連動させ、増減の両方向に効くようにした
  （zoom16・日本中心での実測: `density0.2=25件` … `density1=53件` … `density3=91件`）。

#### 変更

- 同梱する都市データを **Natural Earth `ne_50m_populated_places`（約1,250都市）から
  `ne_10m_populated_places`（約7,340都市）へ差し替え**。
  50m 版は日本付近に11市しか無く、市町村レベルまで拡大すると
  地名が尽きていたため（データ量の限界であり不具合ではない）。
  10m 版では同じ範囲に44市あり、岡山・高松・川崎・宇都宮などの地方都市も表示される。
  **ライセンスは変わらずパブリックドメイン（クレジット表記不要）**。
  - バンドルサイズ: 都市データ 38KB → 221KB（`.spl` は約 1.73MB → 1.91MB）

#### 追加

- **地名の表示量オプション**（`labelDensity`、`editor.slider` / `0.2`〜`5`）。
  地図が地名で埋まりすぎる／少なすぎる場合に調整できる。

### [1.5.0] - 2026-07-28

#### 修正

- **右上のカテゴリフィルタを押してもドロップダウンが開かない不具合を修正**
  （ズームを無効にしたときだけ開く、という症状）。

### [1.4.0] - 2026-07-28

#### 変更（破壊的）

- **色分けを「深刻度（severity）専用」から「任意のカテゴリ列」へ一般化した。**
  この viz の色の根拠は深刻度とは限らず、ログ種別・ステータス・プロトコル・部署など
  何でもありうる。従来は `KNOWN_SEVERITY_ORDER`（`critical`→`high`→`medium`→`low`）で
  **viz が勝手にカテゴリを並べ替え、その順にパレットを配っていた**ため、

- **色は完全にユーザー指定のみに依存する方式へ変更**（`editor.arrayOfStrings`）。
  「カテゴリ名|色」を1行ずつ書き、**書いたものだけが色の根拠になる**。
  viz 側の語彙推測・自動割り当ては一切行わない。
  未指定のカテゴリは `fallbackColor`（既定色）で描き、凡例では破線枠＋ホバー説明で
  「色が未設定である」ことを示す。
- 並び順も `categoryOrder`（`editor.arrayOfStrings`）でユーザーが指定する。
  未指定分は検索結果への登場順（＝同じサーチなら毎回同じ＝決定的）。
- ホットスポットの代表色（同一地点に複数カテゴリが集まる場合）も
  「表示順が先のカテゴリ」＝**ユーザー指定順**に従うようにした。
  「深刻度が高い方を優先」のような意味的判断は行わない。
- オプション名を用途に合わせて改名：`severityField` → `categoryField`、
  `severityColors`（パレット）→ `categoryColors`（明示マッピング）。
- 必須フィールド欠損時のメッセージを日本語化した。

- `severityColors`（`editor.seriesColors` の順序付きパレット）と、

- **旧オプションへのフォールバックは意図的に実装していない**
  （既定値が options に載らないホスト挙動のため、読み替えると
  「既定値を選んだときだけ直らない」不具合になる）。

#### 追加

- 「色分けの呼び名」（`categoryLabel`）。凡例の見出しとフィルタの
  「すべての〇〇」に反映される（例: `ログ種別`）。空欄なら非表示。
- 色指定で基本的な CSS 色名（`red` / `lime` / `navy` 等 22 色）を使えるようにした。

  （従来は `Low` に丸めていた＝深刻度前提の挙動だった）。
- **ホイールズーム / ドラッグ移動**（地図アプリと同じ操作感）。
  マウスホイールで**カーソル位置を固定点に**拡大縮小（`1`〜`40` 倍）、ドラッグでパン、
  ダブルクリック（または右下の `×N ⟲`）で初期表示に復帰する。

### [1.3.0] - 2026-07-25

#### 変更

- **Severity の色設定を「1本の順序付きパレット」に統合した**（`editor.seriesColors` の `severityColors`）。

- 新方式では、サーチ結果に登場した Severity を **凡例の並び順**（既知順 `critical`→`high`→`medium`→`low` を先頭に、
  残りは登場順）に並べ、その順に `severityColors` パレットを上から1色ずつ配る。

  `editor.threshold` が扱う数値レンジには原理的に対応しないため。数値レンジではなく順序付きパレットが正しい型。

  **既定値が options に載らないホスト挙動のため、旧キーへのフォールバックは意図的に実装していない**
  （実装すると「既定値を選んだときだけ直らない」不具合になる）。
  **既存ダッシュボードで線の色を変更していた場合は既定パレットに戻るので、編集画面の「深刻度の色」で設定し直すこと。**
