# Link Line（サーバ間コネクタ線）

![表示例](examples/example.png)

Splunk Dashboard Studio 用のカスタムビジュアライゼーション。
SOC ダッシュボードなどで「サーバ（パネル）同士を線で繋ぎ、接続の状態に応じて線の色を変える」ためのコネクタ線。

## 特徴

- **キャンバス上で線を直接編集**（表示画面の「✎ 線を編集」トグル）
  - 点（○）をドラッグ＝移動
  - セグメント中央の「＋」をドラッグ＝折れ点を追加
  - 中間の点をダブルクリック＝削除
  - **値ラベル（チップ）をドラッグ＝ラベルの位置を移動**（ダブルクリックで線の中央に戻す）。
    既定は線の中央に自動追従。線と重なって読みにくいときに逃がせる
  - 「線をリセット」ボタン＝線の形とラベル位置を既定に戻す
  - 点列は正規化座標(0..1)の JSON としてオプションに保存されるため、編集後に**ダッシュボードの「編集」→「保存」で線の形が確定**する。パネルをリサイズすると線も相対的に追従する
  - ⚠️ Studio の**編集モード中はドラッグ編集できない**（ホストがカスタム viz への入力をパネル選択に使うため）。編集モードでは案内のみ表示し、線の形は表示画面で調整する設計。「表示画面での線編集を許可」オプションでトグルを非表示にもできる
- **シングルバリュー×値の範囲で色分け**（編集画面の右パネル「線の色」＝標準の `editor.threshold`）
  - サーチ結果の値フィールド（既定は「数値を含む最後の列」）の**最終行**を採用
  - 「＋ 閾値の追加」で範囲を動的に増減。各行は「数値2つ（from / to）＋カラーピッカー」（標準 viz の「ゲージ範囲」と同じ UI）
  - `openRanges` 有効なので、**上限なし／下限なしの開区間**も作れる
  - 既定は `0〜40` 緑 / `40〜70` 黄 / `70〜90` 橙 / `90〜` 赤
  - 判定は**半開区間 `[from, to)`**（`40〜70` は 40 を含み 70 を含まない）。上限が開区間の行だけ `[from, ∞)`
  - 範囲が重なるときは「`from` が大きい方 → 同じなら `to` が小さい方 → それも同じなら先に定義した方」を採用（並び順に依存しない）
  - どのバンドにも入らない値・数値でない値・有効なバンドが無い場合はニュートラル色（グレー）
  - ※ v1.9.0 で表示画面の「🎨 色を設定」パネルを廃止し、標準の編集パネルに一本化した（`editor.dynamicColor` はカスタム viz に編集内容が渡らないが、`editor.threshold` は配列が生で届くため使える）
- **文字列の一致で色分けするモード**（「線の色」→「色分けモード」。v1.10.0）
  - `OK` / `NG` / `up` / `down` のような**文字列ステータス**で線の色を決められる（死活監視の線が作れる）
  - 「値と色の対応」に 1 行ずつ `値|色`（例: `OK|#53a051`／`NG|#dc4e41`）。大文字小文字は同一視、CSS 色名も可
  - 一致しない値・値なしはニュートラル色（グレー）。このモードでは値ラベルに生の文字列をそのまま表示する
- **ドリルダウン対応**（v1.10.0）。線のクリックで `line.click` を発火し、値・接続名をトークンに渡せる
  （編集画面の**「インタラクション」**でトークン設定を定義。発火は表示モードのみ。線編集トグル中は無効）
- **値ラベルの単位と接続名**（v1.10.0）
  - 単位（例: `ms`／`%`）を値の後ろに表示。接続名（例: `DB → App`）を値の前に表示
  - 接続名だけのチップ（値ラベル非表示＋接続名あり）も可能
- **質感を選べる**（どんなダッシュボードにも馴染むよう背景は透明）
  - フラット / ソフトシャドウ / ネオン発光 / 立体パイプ（右パネルのドロップダウン）
  - 線幅・破線・**流れアニメーション**（光の帯。**向きは順方向／逆方向／双方向**から選択）・不透明度
  - 両端のコネクタ（丸端子）・終点の矢印・線の中央の値ラベル（小数桁指定可）
- データが無い/数値が無い場合も線は消さず、ニュートラル色（グレー）＋「N/A」で描画（コネクタとしての表示を維持）

## データ仕様

- シングルバリュー。値フィールド（編集パネルで選択。未指定なら「数値を含む最後の列」）の**最終行の値**を使用
- `timechart` の結果を渡した場合は最新値が使われる
- rows / columns 両形式、マルチバリューセルにも対応

## 使い方（Dashboard Studio）

1. `packages/custom_viz_link_line-<ver>-<hash>.spl` を「Install app from file」でインストール（更新時は Upgrade にチェック）
2. ダッシュボードのソース JSON で viz の `type` に `custom_viz_link_line.custom_viz_link_line` を指定（またはビジュアライゼーション一覧の Custom から選択）
3. 編集モードでパネルを繋ぎたい位置・サイズに配置し、右パネルで**「線の色」（値の範囲→色）**・質感などを設定 → 保存
4. **表示画面**に戻り、パネル右上の「✎ 線を編集」で点をドラッグ（＋で折れ点追加／ダブルクリックで削除）。
   **値ラベルもドラッグで好きな位置へ動かせる**（ダブルクリックで中央に戻る）
5. もう一度ダッシュボードの「編集」に入る（この瞬間に線の形とラベル位置が定義へ書き込まれ「保存」が有効になる）→「保存」で確定

### サンプル SPL（動作確認用）

```spl
| makeresults format=csv data="_time,latency_ms
2026-07-22 10:00:00,35
2026-07-22 10:01:00,52
2026-07-22 10:02:00,95"
```

最終行の `95` が採用され、既定バンド（`90〜100`）では線が赤になる。
※ 既定バンドの上限は 100 なので、100 を超える値を扱うときは「線の色」で最上位の範囲の上限を空欄（開区間）にするか、上限を広げること。

ランダムに状態が変わるデモ:

```spl
| makeresults | eval latency_ms=random()%120
```

文字列ステータスで色分けする場合（「色分けモード」を「文字列の一致」にし、
「値と色の対応」に `OK|#53a051`・`NG|#dc4e41` を入力）:

```spl
| makeresults | eval status=if(random()%10<8, "OK", "NG")
```

## 開発

```bash
yarn install
yarn build     # dist/custom_viz_link_line/visualization.js
yarn verify    # happy-dom でのローカル検証（Splunk 実機なし）
yarn package   # dist/custom_viz_link_line-<ver>-<hash>.spl
```

## デプロイ（再起動不要）

1. `package.json` と `package/app/app.conf` のバージョンを上げて `yarn build:prod && yarn package`
2. Splunk Web「Install app from file」で **Upgrade にチェック**してアップロード
3. `https://<host>:8000/en-US/_bump` で Bump version → ブラウザをハードリロード（Ctrl+Shift+R）

### [1.11.0] - 2026-08-08

#### 追加

- **値ラベルの位置を「✎ 線を編集」モードでドラッグして自由に変えられるようにした**。
  従来は線の中央に固定だったため、線が短いときや折れ線のときにラベルが線と重なって
  読みにくくなっていた。編集モード中はラベルの枠が破線になり、掴んで動かせる。
  - **ダブルクリックで中央追従に戻る**（線の折れ点削除と同じ操作感）。
  - **「線をリセット」は線の形とラベル位置の両方**を初期状態に戻す。
  - ラベル位置は線の形とは独立。線を動かしてもラベルは固定されたまま。
  - 表示モードで動かした位置は、線の形と同じく**編集モードに入った瞬間に再送（flush）**
    されるので、ダッシュボードの「編集」→「保存」で永続化される。
  - 位置は 0〜1 の相対座標で持つため、パネルをリサイズしても比率を保つ。

#### 変更

- 通常表示ではラベルはこれまでどおりクリックを透過する（線のドリルダウンを妨げない）。
  掴めるのは線編集モード中だけ。

#### 補足（実装メモ）

- ラベル位置は新しいオプションキー `labelPos` に保存するが、**`config.json` の
  `optionsSchema` には載せていない**。編集パネルに出す必要が無いことに加え、
  `optionsSchema` を増やすと **splunkd の再起動が必要**になるため。
  **スキーマに無いキーもダッシュボード定義に保存され viz に届くことは実機で確認済み**
  （2026-08-08。`config.json` 未変更なので本バージョンの適用に再起動は不要）。
- 壊れた `labelPos`（不正な JSON・数値でない）は中央追従にフォールバックし、
  線本体の描画は巻き込まない。

生成パッケージ: `dist/custom_viz_link_line-1.11.0-0b4475b.spl`

### [1.10.3] - 2026-08-08

#### 修正

- **矢印（終点）から線がはみ出す問題を修正**。線本体は終点まで引かれており、
  矢印の先端と同じ座標で `strokeLinecap="round"` の半円が描かれていたため、
  矢印の内側ノッチから線が突き出て見えていた。矢印ONのときは終端セグメントを
  内側ノッチ付近（`arrowLen * 0.62`）まで縮めて描くようにした。
  流れる光の帯（Canvas）も同じ点列を使うため、帯が矢印を突き抜けなくなった。
- **太い線で矢印の羽より線が広くなる問題を修正**。羽の半幅を
  「線の実体（立体パイプの暗い縁 `lw * 1.45` を含む）より必ず広く」なるよう
  下限を設けた。ぼかしのハロー（ネオン）は実体ではないため基準に含めない
  （含めると矢印が過大になる）。
- 上記の縮めは**見た目の線だけ**に適用し、**ドリルダウンの当たり判定は全長のまま**
  にしてある（矢印の先端付近をクリックしても `line.click` が発火する）。
- 短い線で線が消えないよう、縮める量はパス全長の 45% を上限にクランプしている。

生成パッケージ: `dist/custom_viz_link_line-1.10.3-8e12d2d.spl`

### [1.10.0] - 2026-07-30

#### 追加

- **色分けモード「文字列の一致」**（「線の色」→「色分けモード」、`editor.select`）。
  `OK` / `NG` のような文字列ステータスで線の色を決められる。対応は
  「値と色の対応」（`editor.arrayOfStrings`）に 1 行ずつ `値|色` で入力する
  （world-map の「カテゴリ名|色」と同じ書式。大文字小文字は同一視・CSS 色名可・
  解釈できない行は黙って無視）。一致しない値はニュートラル色。
  このモードでは値ラベルに生の文字列をそのまま表示する（数値でも整形しない）。
  v1.9.0 で廃止した旧「一致」方式の復活だが、旧オプション（`colorMethod` /
  `colorMatches`）との互換は無く、新キー `colorMode` / `matchColors` を使う。
- **ドリルダウン対応**。`config.json` に `showDrilldown` / `hasEventHandlers` /
  `canSetTokens` と `events`（`line.click`）を宣言し、線の透明な当たり判定に
  `addDrilldownListener` で登録した。payload は `row.<値フィールド名>.value` /
  `row.value.value` / `row.label.value`（接続名）/ `name` / `value`。
  トークンへの割り当ては編集画面の「インタラクション」で定義する
  （発火は表示モードのクリックのみ。線編集トグル中は当たり判定を外す）。
- **値ラベルの単位**（`unitLabel`、`editor.text`）。値の後ろに一段小さく表示する
  （例: `95 ms`）。数値表示のときだけ付き、N/A や文字列ステータスには付かない。
- **接続名**（`linkLabel`、`editor.text`）。値の前に一段弱いウェイトで表示する
  （例: `DB → App 95 ms`）。値ラベル非表示でも接続名だけのチップを出せる。
- **光の帯の向き**（`flowDirection`、`editor.select`）。順方向（既定）／逆方向／
  双方向。双方向は同位相の帯を両方向に描く。

#### 変更

- **「光の帯の速度」と「不透明度」を `editor.slider` に変更**（従来は `editor.number`）。
  範囲が決まった連続量のため。値の意味・範囲は従来どおり（速度 0〜10 / 不透明度 10〜100%）。

#### 成果物

- `dist/custom_viz_link_line-1.10.0-8e6f807.spl`
- ローカル検証（`yarn verify`）: **181 件すべて成功**（今回 28 件追加。
  文字列一致の色分け・単位/接続名・帯の向き・ドリルダウン登録・slider 化を検証）。

  未知の値はすべて `フラット` へ丸めます。

### [1.6.0] - 2026-07-22

#### 変更

- **流れアニメーションを world-map と同方式の「光の帯」（Canvas）に刷新**

  - 端点パルスも同じ Canvas の rAF ループに統合し、SVG の毎フレーム属性書き換えを全廃。アニメーション停止時（速度0・パルスなし）は Canvas 自体をマウントせず rAF ゼロ（CPU 0）で軽量

- 値ラベルのチップを SVG から HTML に移動（光の帯がラベルの上を通って重ならないように Canvas より上のレイヤーへ）
