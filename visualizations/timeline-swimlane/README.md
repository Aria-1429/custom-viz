# Timeline Swimlane

![表示例](examples/example.png)

Splunk **Dashboard Studio** 向けのカスタムビジュアライゼーション（React/JSX）。

ホスト／ユーザー／プロセスなどのエンティティごとに「レーン」を作り、各イベントを時刻順の
**帯（期間イベント）** または **点（瞬間イベント）** で並べるタイムラインです。

インシデント調査で最も欲しい「**誰が・いつ・何をしたか**」の時系列並置は、
Splunk 標準の `timechart`（集計されて個々のイベントが消える）や Events テーブル
（レーンに分割できない）では再現できません。

---

## 特徴

- **期間イベントと点イベントの両対応** — 終了時刻フィールドがあれば帯、無ければ点として描画。
- **多様な時刻形式を自動解釈** — epoch 秒 / epoch ミリ秒 / ISO 文字列 / `2026-07-25 09:00:00` 形式。
  解釈できない行は自動的に除外し、件数を注記に表示。
- **スクラブ用クロスヘア** — カーソルを乗せると時刻の縦線と時刻チップが出て、
  その瞬間に**重なっているイベントだけが浮かび上がり、他は退く**。
  「18:25 に何が起きていて、誰が巻き込まれていたか」を縦一列で読むための仕掛け。
  凡例の右端に「時刻 — N 件」を表示。
- **分類（色分け）** — 分類フィールドの値ごとに 8 色のパレットを巡回。全色を編集画面で変更可能。
  パレットは色覚特性（第2色覚）でも隣接色が潰れないよう色相を広く取ってある。
- **ドラッグで時間範囲を絞り込み** — 表示モードで横方向にドラッグすると、その範囲に拡大。
  ダブルクリックで全体に戻る。範囲はオプションに保存され、編集→保存でダッシュボードに永続化できる。
- **時間軸の自動目盛り** — 表示期間の長さに応じて「切りのよい」間隔とラベル書式（秒/分/時/日/月）を自動選択。
  目盛りはローカルの日境界に合わせて刻むため、日付がずれない。
- **オートフィット** — `ResizeObserver` でコンテナ実寸を測り、**レーンの高さをパネルの高さから自動計算**。
  パネルを縦に広げるとレーンも一緒に太くなり、下に余白が残らない。
  レーンが 1〜2 本しかないときに極端に太くならないよう高さ上限（既定 60px）を設けており、
  上限に当たって余った分はプロット全体を上下中央に寄せて処理する。
  レーンが多いときは 10px まで詰めたうえで自動的に縦スクロールへ退避。
- ライト／ダーク両テーマ対応、完全オフライン（外部通信なし）。

## データ仕様

| 役割 | 必須 | 説明 |
| --- | --- | --- |
| レーン（縦軸） | 任意 | エンティティ名（host / user / process など）。省略時は全イベントが1レーン。 |
| 開始時刻 | **必須** | epoch 秒 / epoch ミリ秒 / ISO / `YYYY-MM-DD HH:MM:SS`。 |
| 終了時刻 | 任意 | 省略・逆転・欠損時はその行を点イベントとして描画。 |
| 分類（色分け） | 任意 | 値ごとに色を割り当て、凡例に表示。 |
| ラベル | 任意 | ツールチップとバー内ラベルに使う。 |

### 列の自動判定

編集画面でフィールドを選択しなかった場合、以下の順で自動判定します（明示選択が常に優先）。

- **開始時刻** … 名前が `_time` / `start` / `begin` / `first` / `earliest` 系の時刻列 → 最初の時刻列
- **終了時刻** … 名前が `end` / `finish` / `last` / `latest` 系の時刻列 → 開始列以外の時刻列
- **レーン** … 時刻列・数値列以外の最初の列（`_` 始まりの内部フィールドは除外）
- **分類** … レーン列・時刻列以外の最初の非数値列
- **ラベル** … 自動では選ばない（明示選択のみ）

## サンプル SPL

### 1. 期間イベント（推奨・調査で最もよく使う形）

`stats` で開始／終了をまとめると、ホストごとのアクション期間がそのまま帯になります。

```spl
| makeresults format=csv data="host,action,start,end
web-01,login,1784970000,1784970300
web-01,query,1784970600,1784971500
web-01,logout,1784972000,1784972060
web-02,login,1784970120,1784970200
web-02,error,1784970900,1784970960
web-02,query,1784971200,1784972400
db-01,query,1784970300,1784973600
db-01,backup,1784973700,1784976000
api-01,deploy,1784969000,1784971000
api-01,error,1784971100,1784971400"
| eval start=tonumber(start), end=tonumber(end)
| table host action start end
```

### 2. 点イベント（終了時刻なし）

```spl
| makeresults format=csv data="_time,user,action
1784970000,alice,login
1784970300,alice,search
1784970900,alice,logout
1784970100,bob,login
1784971500,bob,failed_auth
1784971560,bob,failed_auth
1784971620,bob,failed_auth
1784972000,carol,login"
| eval _time=tonumber(_time)
| table _time user action
```

### 3. 実データでの典型パターン

```spl
index=main
| stats min(_time) as start max(_time) as end count by host, action
| sort - count
```

```spl
index=wineventlog
| stats min(_time) as start max(_time) as end by user, EventCode
```

## 編集画面のオプション

| セクション | 項目 | 説明 |
| --- | --- | --- |
| データフィールド | レーン／開始時刻／終了時刻／分類／ラベル | 各フィールドの明示選択（未設定は自動判定） |
| 分類の色 | 分類1〜8の色 | 分類値へ出現順に割り当てる色。9件目以降は繰り返し |
| レーン | 高さの自動調整／高さ上限／高さ／最大数／縞模様／レーン名／件数 | 既定は自動調整オン（パネル高さに追従）。オフにすると「レーンの高さ（px）」で固定。上限超過分は省略し注記を表示 |
| イベントバー | 最小幅／角丸／不透明度／ラベル表示 | バーの見た目。点イベントは最小幅で描画される |
| 時間軸 | 軸／グリッド線／時刻の縦線／現在時刻の線／余白（％） | 軸まわりの表示。「カーソル位置に時刻の縦線を表示」が既定オンのクロスヘア |
| 表示範囲の固定（任意） | 表示開始時刻／表示終了時刻 | 空欄でデータ全体。`2026-07-25 09:00` 形式 |
| 表示 | 凡例／アニメーション／ドラッグで絞り込み | |
| デバッグ | オプションのデバッグ表示 | 解決した列・時間範囲・オプションをダンプ |

## 開発コマンド

```bash
yarn install
yarn build        # dist/custom_viz_timeline_swimlane/visualization.js を生成（esbuild）
yarn verify       # happy-dom によるローカル検証（Splunk 実機不要）
yarn package      # dist/*.spl を生成
```

## デプロイ（アンインストール・再起動なし）

1. `npm version <patch|minor> --no-git-tag-version` でバージョンを上げ、`package/app/app.conf` の version も同期。
2. `yarn build:prod && yarn package` で新しい `.spl` を生成。
3. Splunk Web「Install app from file」で **"Upgrade app"（上書き）にチェック**して `.spl` をアップロード。
4. `https://<host>:8000/en-US/_bump` で **Bump version** → ブラウザをハードリロード（Ctrl+Shift+R）。

### [1.3.3] - 2026-08-09

#### 修正

- **スピナーが永遠に回り続けることがある問題への対策**（全 viz 共通の横展開）。
  公式 `useDataSources` は「render 時に現在値でシード → `useEffect` で購読」の構造で、
  その間に届いた更新を取り逃す（ホストは購読登録時に現在値を再送しない）。
  サーチ完了の最終通知をこの隙間で落とすと `loading` のまま固まる。対策として、
  loading 中は `getDataSources()` を 500ms 間隔で読み直し、ホスト側が完了済みなら
  その値を採用する（`useDataSourcesWithRescue`）。完了後はポーリングしない。
  不定期・初回表示時に発生しやすく、リロードで直る症状はこれが原因とみられる。
  描画・オプションの挙動に変更はない。

`.spl`: `dist/custom_viz_timeline_swimlane-1.3.3-2bb5ec3.spl`

### [1.3.0] - 2026-07-25

#### 変更

- 分類の色設定を `editor.color` 8個（`color1`〜`color8`）から **`editor.seriesColors` 1項目**（`seriesColors`）へ統合。編集画面が「プリセット選択＋色スウォッチ列」になり、色数もユーザーが増減できるようになった。
- パレットが分類数より少ない場合は循環して適用する（既定色に落ちない）。
- `optionsSchema.seriesColors` は `anyOf`（文字列配列 ＋ DOS 文字列 `^>.*`）で宣言し、保存時検証で落ちないようにした。
- 既定パレットが `config.json`（`#4a90d9` 系）と実装（`#4c9be8` 系）で食い違っていたのを、実際に描画に使われていた実装側の値へ統一した。

#### 削除

- 旧オプション `color1`〜`color8`。**既定値が options に載らないホスト挙動のため、旧キーへのフォールバックは意図的に実装していない**（実装すると「既定値を選んだときだけ直らない」不具合になる）。既存ダッシュボードで色を変更していた場合は既定パレットに戻るので、編集画面で設定し直すこと。
- 旧オプション `debug`（「デバッグ」セクションとオプションのデバッグ表示オーバーレイ）。設定パネルからセクションごと削除した。
