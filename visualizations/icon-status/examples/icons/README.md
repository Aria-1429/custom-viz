## 撮影のめやす

表では `width="72"` で表示するので、**144〜240px 角**（2倍〜3倍）で撮ると高 DPI 環境でも綺麗に出る。
正方形で、アイコンの周囲に少し余白を取ると表の中で揃って見える。

撮り方の例:
- 編集画面で「数値を表示」「ラベルを表示」「カード背景を表示」をすべて OFF にし、
  アイコンだけの状態にしてパネルを正方形にしてから撮る
- 背景を統一する（ダークテーマで撮るなら 12 枚とも同じテーマで揃える）
- 色は既定のしきい値バンドのままでよい（値を変えると色が変わるため、
  一覧としては1色に揃っているほうが形を比較しやすい）
